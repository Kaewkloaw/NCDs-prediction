## 📄 Project Description
<p style="text-align: justify; line-height: 1.6;">
  The <strong>Patient Dashboard</strong> is a modern, client-side healthcare management demonstration designed to showcase the future of clinical information systems. It features a robust interface for <strong>vital-sign visualization</strong>, real-time <strong>anomaly detection</strong>, and <strong>voice note recording</strong> using WebRTC. Built entirely with vanilla HTML, CSS, and JavaScript, this project runs directly in the browser with zero backend requirements. It utilizes advanced linear regression algorithms to provide <strong>personalized health forecasts</strong> and risk assessments, making it an ideal prototype for exploring medical data trends and predictive healthcare analytics. 🌸
</p>

## ✨ Key Features
* 🌸 **Patient Demographics & Search:** Quick search functionality by Patient ID or Name with a full demographic overview.
* 🌷 **Real-Time Anomaly Detection:** Automatic alerts for hypertension, tachycardia, and weight fluctuations based on rule-based logic.
* 🌺 **Voice Note Integration:** Click-to-record voice notes using the MediaRecorder API, with local playback and storage.
* 💐 **AI Health Forecasting:** Predictive modeling for weight and blood pressure trends with confidence scoring and interactive Chart.js visualizations.
